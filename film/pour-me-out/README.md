# Pour Me Out: animated music video

Kashus Culpepper, "Pour Me Out" (Big Loud, released 22 Nov 2024). Character: **Little KC, 07 Soulful Artist** (locked, no redesigns).

Open `index.html` in a browser. It holds the full-song timeline, the opening storyboard, the reusable performance sequences and the artwork list.
The data is in plain lists at the bottom of that file. To change the plan, edit those lists.

## Layout

- `index.html`: the board (static page, no build)
- `shots/SHxxx-name/`: one folder per shot, with a `README.md` (beats, cues, art status) and `boards/` (rough sketches, timing notes). Make a folder only when work on that shot starts.
- `audio/`: the local recording. Git ignores it; see `audio/README.md`.

Approved art stays where it is, in `character-dev/004/`. The board links to it and never copies or modifies it.
